Wipe Agent Memory

Purges all persistent vectorized memory for CrewAI agents. The agents will lose their context of past cases, but will continue to process active claims perfectly based on their base instructions. Use this to free up database limits on the free tier.

Wipe System Logs

Deletes all historical records of admin overrides, manual verdicts, and account suspensions. This does NOT delete user claims or evidence files. The automated weekly cleanup will continue to prune these automatically, but this offers a full manual reset.

Reset Rate Limits
